# ڕێبەری دانانی سیستەمی بەنزینخانە (Feul Station Pro) لەسەر کۆمپیوتەری بەنزینخانەکان

ئەم سیستەمە بە شێوەی **Windows Desktop Application** ئامادە کراوە بە ئاسانترین شێواز:

---

## هەنگاوەکان بۆ کۆمپیوتەری هەر بەنزینخانەیەک:

### هەنگاوی ١: دابەزاندنی پرۆژەکە
پرۆژەکە دابەزێنە یان فۆڵدەری پرۆژەکە کۆپی بکە بۆ سەر کۆمپیوتەرەکە.

### هەنگاوی ٢: دامەزراندنی خێرا بە یەک کلیک (1-Click Install)
* تەنها دوو کلیک لەسەر فایلی **`Setup-Desktop-App.bat`** بکە.
* فایلەکە بە شێوەیەکی ئۆتۆماتیکی:
  1. پێداویستییەکان دادەمەزرێنێت.
  2. ئایکۆنی تایبەت بە کوالێتی بەرز (3D Gas Pump Icon) دروست دەکات.
  3. کورتەبڕی دیسکتۆپ (**Feul Station Pro.lnk**) لەسەر ڕووی شاشەی کۆمپیوتەرەکەت (Desktop) دروست دەکات.

---

## دەستپێکردن و بەکارهێنان:
* هەرکاتێک ویستت سیستەمەکە بکەیتەوە، تەنها لەسەر دیسکتۆپ دوو کلیک لەسەر ئایکۆنی **Feul Station Pro** بکە.
* سیستەمەکە ڕاستەوخۆ وەک بەرنامەیەکی فەرمیی ویندۆز (Desktop App) بە پەنجەرەی تایبەت و بێ ناوەڕۆکی وێبگە دەکرێتەوە.
* کلیلی **`F11`** دابگرە بۆ پڕاوپڕکردنی شاشە (Full Screen POS Mode).
* کاتێک پەنجەرەکە دادەخەیت، سیستەمەکە بە خاوێنی کۆتایی دێت.
