# وێب ئەپی بەنزینخانە (Feul Station Pro)

سیستەمێکی مۆدێرن و پڕۆفیشناڵە بۆ تۆمارکردن و بەڕێوەبردنی پێدانی بەنزین بە ئۆتۆمبێلەکان لە بەنزینخانەکان بە بەستنەوەی ڕاستەوخۆ بە سێرڤەری **Microsoft SQL Server**.

## 🌟 تایبەتمەندییە سەرەکییەکان
1. **فۆرمی لۆگ ئین (Login Form)**:
   - چوونەژوورەوە بە زانیارییەکانی خشتەی `USERS` لەناو داتابەیسی `Feul`.
   - پشکنینی کارابوونی بەکارهێنەر (`on_off = 'yes'`).
   - دیاریکردنی وێستگە و بەنزینخانە.

2. **فۆرمی تۆمارکردنی ئۆتۆمبێل (Registration Form)**:
   - **ژمارەی ئۆتۆمبێل**: تەنها ژمارە و پیتی ئینگلیزی (بە پیتی گەورە - Uppercase).
   - **پارێزگا**: کۆمبۆبۆکس (هەڵبژاردن و نووسینی دەستی).
   - **بەش**: کۆمبۆبۆکس (تایبەت، کرێ، بارهەڵگر، حکومی، کشتوکاڵی، هتد).
   - **بەروار و کاتژمێر**: بە شێوەی خودکار لەگەڵ کاتژمێری ڕاستەوخۆ.
   - **ناوی بەنزینخانە**: ناوی وێستگەکە.

3. **یاسای هەفتانە (7-Day Fuel Rule)**:
   - هەر ئۆتۆمبێلێک لە ماوەی ٧ ڕۆژدا تەنها یەک جار مافی وەرگرتنی بەنزینی هەیە.
   - **لە کاتی دووبارەبوونەوەدا**:
     - فۆرمەکە بە ڕەنگی **سوور** دەدرەوشێتەوە بە ئەنیمەیشنی لەرزین.
     - دەنگی ئاگاداری لێدەدرێت (Buzzer).
     - پەیامی ئاگاداری ڕوون بە بەروار و کاتی پێشوو و وێستگە و ڕۆژانی ماوە پیشان دەدرێت.
     - خانەکانی فۆرمەکە بە خودکاری بەتاڵ دەبنەوە تاوەکو کارمەند ڕاستەوخۆ ئۆتۆمبێلی دواتر بنووسێت بەبێ پێویستی بەکارهێنانی ماوس.
   - **لە کاتی سەرکەوتندا**:
     - فۆرمەکە بە ڕەنگی **سەوز** دەدرەوشێتەوە و دەنگی سەرکەوتن لێدەدرێت.
     - تۆمارەکە لە سێرڤەر خەزن دەکرێت و فۆرمەکە بۆ ئۆتۆمبێلی نوێ ئامادە دەبێتەوە.

4. **خشتەی تۆمارکراوەکانی ئەمڕۆ**:
   - لیستی هەموو ئەو ئۆتۆمبێلانەی ئەمڕۆ بەنزینیان بردووە لەگەڵ ژماردەری گشتی و گەڕانی خێرا.
   - دوگمەی چاپکردنی ڕاپۆرتی ڕۆژانە.
